# Maintainer publication status

This repository is independent of [the Windows tray fork](https://github.com/arussin/codex-usage). Keep tray source, patches and binaries out of this tree.

The first source publication is prepared by the owner-approved local publishing kit. The kit verifies GitHub's native fork parent, builds/tests in isolation, retains the upstream license, publishes source without force-pushing, and leaves binary releases as drafts.

Before making the exporter draft public, complete [the release checklist](RELEASE_CHECKLIST.md). Then insert the actual tested binary-release URL in [the setup guide](CODEX_SETUP.md). Keep the README short; put technical details in linked pages.

Never upload personal source URLs, credentials, real usage snapshots, or phone screenshots. Community announcements and an upstream PR are separate actions, not part of publication.
