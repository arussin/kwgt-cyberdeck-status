All modifications to that application must live in a **direct GitHub fork of `Tooblippe/codex-usage`**, retaining upstream history and the original [MIT license and notice](https://github.com/Tooblippe/codex-usage/blob/main/LICENSE).

The intended fork is `arussin/codex-usage`; this is a publishing plan, not a claim that it already exists. Before release, verify GitHub reports `fork: true` and `parent.full_name: Tooblippe/codex-usage`. GitHub's own fork relationship must be visible; a README link is not a substitute. Keep a short summary of the exporter changes in the fork.

**Do not add tray source, copied snippets, derivative patches, or tray binaries here.** Link to the real fork and its releases instead. This also applies to downloadable widget bundles; no vendored copy or submodule checkout is included.
